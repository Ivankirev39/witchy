# Witchy 🌙

Witchy is a university semester project created as part of the Web Development programme.

The concept is a visual community platform for people interested in witchcraft, Paganism, spirituality, divination, folklore and related topics.

The project combines three main areas:

## UX
The UX part focuses on understanding the users and designing the platform based on research.

This includes:
- Surveys
- User interviews
- Competitor research
- User archetypes
- Customer journey
- Feature prioritisation
- Wireframes and prototypes in Figma

## Database
The database part focuses on designing and implementing the data structure for Witchy.

It includes:
- ER diagram
- Relational Data Model (RDM)
- Database normalisation
- SQL database implementation
- Tables and relationships for users, posts, comments, likes, saves, follows, badges, rules and bans

## PHP
The PHP part focuses on connecting the website to the database and implementing the main functionality.

This includes:
- Database connection with PDO
- User registration and login
- Creating and displaying posts
- Comments
- Likes
- Saved posts
- Following users
- User profiles
- Basic moderation features

## Status

The project is currently in development and is created for educational purposes.
